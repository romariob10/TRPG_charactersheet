# Перенос листа персонажа между серверами

В редакторе листа нажмите **Экспорт JSON** после автосохранения. Файл
`*.mycharacter.json` содержит шаблон: макеты desktop, tablet, mobile и print,
названия, типы, ключи и начальные значения полей. Данные заполненных персонажей,
аккаунты, права доступа и ID системы в него не входят.

Компоненты библиотеки экспортируются как обычные редактируемые фреймы с уже
применёнными свойствами. На другом сервере не требуется устанавливать исходную
библиотеку. Ссылки на статические изображения сохраняются; сами файлы изображений
не упаковываются. Портрет заполненного персонажа не переносится с шаблоном.

На rodev.cc создайте систему и откройте нужный лист в её редакторе. Нажмите
**Импорт JSON**, выберите файл и подтвердите замену черновика. После автосохранения
опубликуйте версию, чтобы создавать персонажей по этому листу. Импорт можно
отменить через Undo. Опубликованные версии и существующие персонажи не меняются.

Формат: `format: "mycharacter-sheet"`, `formatVersion: 1`, `title`, `layouts`,
`fields`. Максимальный размер файла — 1 МБ. Неподдерживаемая версия, слишком
глубокий макет, повторяющиеся поля, отсутствующие привязки или неразрешённые
компоненты отклоняются до замены черновика. Обе локализации поддерживаются.

Для автоматизации доступны защищённые маршруты:

- `GET /api/sheet-definitions/:id/export` — экспорт сохранённого черновика;
- `POST /api/sheet-definitions/:id/import` — `{ expectedRevision, document }`.

Импорт требует прав владельца и актуальной ревизии. Конфликт ревизий возвращает
409; некорректный файл — 400. Приложение проверяет origin cookie-запросов.

PDF использует отдельный статический print-макет. В Fate Core это одна страница
A4; длинный текст в PDF ограничивается рамкой, а в экранном макете увеличивает
высоту поля. Это предотвращает смещение соседних секций при печати.
